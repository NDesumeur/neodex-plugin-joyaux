# Joyaux

Échange deux pierres voisines pour en aligner trois ou plus de la même sorte. Les chaînes en cascade multiplient les points ; 25 coups par partie.

Aligne trois pierres pareilles (ou plus) en échangeant deux voisines. Les pierres alignées disparaissent, les autres tombent et de nouvelles arrivent ; chaque chaîne rapporte davantage. 25 coups pour le meilleur score.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Joyaux → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
